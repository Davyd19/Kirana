# Kirana

Kirana dipisah menjadi dua bagian.

- [Backend](backend/README.md) mengelola kuis, sesi siswa, dan laporan guru.
- [Machine learning](ml/README.md) berisi dataset sintetis, logika simulasi, training, notebook, prediksi, dan evaluasi.

Training dijalankan saat diperlukan. Flask memuat model hasil training saat server backend dimulai.
